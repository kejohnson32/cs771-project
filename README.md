# DeepWater: Water Level Estimation from Camera Images

A computer vision system for estimating water levels from USGS monitoring camera images using deep learning.

## Project Overview

We compare four model architectures for water level estimation:
- **Siamese RGB**: Uses 1 reference image with known water level (3-channel input)
- **Siamese SAM**: Siamese with SAM2 water segmentation mask (4-channel input)
- **Triplet RGB**: Uses 2 reference images with known water levels (3-channel input)
- **Triplet SAM**: Triplet with SAM2 water segmentation mask (4-channel input)

### Key Results

| Model | Seen Sites (MAE) | Seen R² | Unseen Sites (MAE) | Unseen R² |
|-------|------------------|---------|-------------------|-----------|
| Siamese RGB | 1.58 ft | 0.316 | 1.90 ft | -0.725 |
| **Siamese SAM** | **1.46 ft** | **0.469** | 1.69 ft | -0.383 |
| Triplet RGB | 1.56 ft | 0.342 | 1.67 ft | -0.538 |
| Triplet SAM | 1.72 ft | 0.248 | 1.53 ft | -0.359 |

### Key Findings

1. **Generalization remains challenging**: All models achieve positive R² on seen sites but negative R² on unseen sites, indicating predictions worse than the mean baseline.

2. **SAM augmentation helps on seen sites**: Siamese SAM achieves the best seen-site performance (R² = 0.469), suggesting explicit water segmentation helps focus on relevant features.

3. **Significant seen-to-unseen gap**: Average R² drops by ~0.8 when moving from seen to unseen camera sites.

4. **Camera perspective is the key challenge**: Each site has unique camera angles, making absolute water level appearance highly site-dependent.

## Installation

```bash
# Clone repository
git clone https://github.com/kejohnson32/cs771-project.git
cd cs771-project

# Create virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# (Optional) For SAM models, install SAM2
git clone https://github.com/facebookresearch/segment-anything-2.git sam2
cd sam2 && pip install -e . && cd ..
```

## Data

### Download Data
```bash
python scripts/collect_quality_data.py
```

This downloads images from 21 USGS camera sites and creates:
- `data/quality_dataset.csv` - Full dataset (5,035 images)
- `data/train_quality.csv` - Training set (14 sites)
- `data/val_quality.csv` - Validation set (3 sites)
- `data/test_quality.csv` - Test set (4 unseen sites)

### Data Splits

**Cross-site split** (for true seen vs unseen evaluation):
- **Train**: 14 sites (seen during training)
- **Validation**: 3 sites
- **Test**: 4 sites (completely unseen cameras)

## Training

### Siamese Models
```bash
# Siamese RGB (3 channels)
python scripts/train_siamese_rgb.py --epochs 15

# Siamese SAM (4 channels with water mask)
python scripts/train_siamese_sam.py --epochs 15
```

### Triplet Models
```bash
# Triplet RGB (3 channels)
python scripts/train_triplet_rgb.py --epochs 15

# Triplet SAM (4 channels with water mask)
python scripts/train_triplet_sam.py --epochs 15
```

## Evaluation

### Create Evaluation Datasets
```bash
# Generate seen_eval.csv and unseen_eval.csv
python scripts/create_seen_eval.py
```

### Run Evaluation
```bash
# Evaluate all models on seen vs unseen sites
python scripts/eval_seen_unseen.py
```

Results are saved to `outputs/eval_results/`:
- `results.json` - All metrics
- `model_comparison.png` - Bar chart comparison
- `{model}_seen.png` / `{model}_unseen.png` - Scatter plots
- `{model}_comparison.png` - Side-by-side plots

## Architecture

### Siamese Model
```
Image 1 (Reference) ──┐
                      ├──> ViT-Tiny Backbone ──> Concat ──> MLP Head ──> Prediction
Image 2 (Query) ──────┘                           ↑
                                                  │
Water Level 1 ──> Elevation Embedding ────────────┘
```

### Triplet Model
```
Image 1 (Ref 1) ──┐
Image 2 (Ref 2) ──┼──> ViT-Tiny Backbone ──> Cross-Attention ──> Concat ──> MLP ──> Prediction
Image 3 (Query) ──┘                                               ↑
                                                                  │
Water Levels 1 & 2 ──> Elevation Embedding ───────────────────────┘
```

## Future Work

- Train on larger, more diverse set of camera sites
- Incorporate camera metadata (angle, focal length) as model inputs
- Use explicit geometric reasoning about water surface position
- Implement few-shot adaptation for new sites
- Deploy SAM2 with proper water segmentation prompts
